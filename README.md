# Deck Shooter

Roblox PvP deck-building shooter. GitHub is the source of truth for code.

## Tests

    lune run tests/run.luau

## Live sync into Studio

    rojo serve

In Studio, open the place, then Plugins > Rojo > Connect. Saved code changes then appear in Studio.

## Build a place file

    mkdir build
    rojo build -o build/DeckShooter.rbxl
