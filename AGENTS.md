# Notes for coding agents

Read `docs/HANDOFF.md` first. It explains the project, how River works, and where things stand.

**Every coding session ends pushed to GitHub.** When the work is finished and `lune run tests/run.luau` passes, merge the session's branch into `main` with `--no-ff` and push `main` and the branch to `aprilfridae/deck-shooter`. Then confirm `main` matches `origin/main` and `git status` is clean.

The repo is code only. Never commit `assets/`, place files or API keys. Sounds, images and models live with the Fridae Studios group on Roblox.
