# Card Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the server-owned card layer: card data, 3 rarity tiers, fusion, Deck Power Rating, collection income and save data.

**Architecture:** All rules live in pure Luau modules in `src/shared/CardCore/`, which take a plain save-data table and never touch Roblox APIs. They are tested outside Studio under Lune. A thin server layer in `src/server/` adds persistence, remotes and the income loop, and is checked by a Studio smoke test.

**Tech Stack:** Luau, Rojo 7.7.1, Lune 0.11.1, Rokit (tool pinning), ProfileStore (vendored).

**Spec:** https://claude.ai/artifact/P6cgJtFzpNRJJcx53PMoMH (Deck-Shooter Design Spec, rev 13; sections "Combat and ability cards", "Economy and market", "Matchmaking", "Technical, compliance and risks")

## Changes from the handoff

- **Test runner: a small Jest-style harness on Lune, not Jest-Lua.** The [Jest-Lua README](https://github.com/jsdotlua/jest-lua) says it "can currently only run inside of Roblox", and [issue #2](https://github.com/jsdotlua/jest-lua/issues/2) on porting it is still open. The goal (logic tests outside Studio) is unchanged. `tests/harness.luau` copies the `describe / it / expect` shape, so tests port easily if Jest-Lua gains Lune support.
- **Persistence: ProfileStore, vendored.** It is the same author's successor to ProfileService and matches the spec's "ProfileService-style" session locking. The source comes from [MadStudioRoblox/ProfileStore](https://github.com/MadStudioRoblox/ProfileStore), because a Wally package could not be confirmed.

## Plan decisions (the spec leaves these open)

Each one lives in `Config.luau` or `Cards.luau`, so it can change without touching logic.

| Decision | Value | Why |
| --- | --- | --- |
| DPR tier points | Field 100, Black-Site 112, Prototype 125 | 1/2/3 points cannot express the spec's "10–15% higher DPR" lobby: one upgrade from 3 is already +33%. These values mirror the example cards' real stat gains, so 1% DPR is about 1% power. Range is 300–375. |
| Gun weight in DPR | 3 points per gun upgrade level | "Smaller weight" than a card's 12-point step. Gun upgrades are not designed yet, so levels default to 0. |
| Fusion fee | Field→Black-Site 100 Credits; Black-Site→Prototype 600 Credits | About 200 seconds of the 5 input cards' income, which keeps the fee "small" at both tiers. |
| Catalyst and the fee | The full fee still applies | The spec only says the Catalyst reduces copies. |
| Income of Redacted and Zero-Day | 2.5x and 5x | The spec pins only Chromatic at 1.5x. |
| Soft cap scope | Per card and tier, all variants together; the best-paying copies fill the first 10 slots | The spec says "a card's 11th copy". This never punishes owning a variant. |
| Starter cards | 1 Field copy each of Phase Dash, Overclock, Recon Pulse, equipped | The spec requires exactly 3 cards, so a new player needs a full deck. |
| Fusion and variants | Base copies are spent first; spending a variant needs explicit confirmation | Variants are the whale market's stock, so losing one by accident is costly. |
| Deck slot after fusion | If fusion spends the last copy at the equipped tier, the slot moves to the new tier | Keeps the deck valid and makes the upgrade feel immediate. |
| Tick clamp | Income credits at most 5 seconds per tick | Stops a server stall paying a lump sum. |

**Out of scope:** rolling and pity, market, Robux purchases and ProcessReceipt, matchmaking, UI, serialized seasonals. `Variant.roll` is here only because fusion can produce a variant. Save data has a `version` field, so serialized copies can be added by migration.

## Spec conflicts to confirm

The plan copies these values verbatim. Changing one is a one-line edit in `Cards.luau`.

- **Two stats break the 20–25% ceiling.** Aegis Shell duration (3s → 4s) and Arc Mine slow time (1.5s → 2s) both rise 33%. They are marked ceiling-exempt so the ceiling test can guard everything else. Staying inside it would mean about 3.75s and 1.9s.
- **Arc Mine's perk may break "never adds damage".** Holding 2 charges can double its damage per use, at 75 each.
- **Four example cards have no cooldown.** Only Phase Dash lists one. The combat plan must set the rest, so this plan does not invent them.

## Global Constraints

- The server owns every card, Credit and roll result; the client only displays them.
- Modules in `src/shared/CardCore/` use no Roblox APIs and take any randomness as an injected `rng: () -> number` returning [0, 1).
- Shared modules sit in one flat folder, have no `init.luau`, and require siblings with `require("./Name")`.
- A failed operation changes nothing in save data.
- Tiers run Field → Black-Site → Prototype. Core stats rise 20–25% in total. The Prototype perk is utility and never adds damage.
- Exactly 2 guns plus 3 different cards. A deck cannot hold duplicate cards.
- Fusion: 5 copies at the same tier → 1 at the next tier; 4 with a Fusion Catalyst. Fusion is never random in outcome tier, and duplicates cannot be converted to currency.
- Income pays only while in game. Credits/sec per card: Field 0.1, Black-Site 0.6, Prototype 3.5. Set bonus +10%. 11th copy onward pays half.
- Variant odds: Chromatic 1/50, Redacted 1/500, Zero-Day 1/5,000. Variants add income, never combat power.
- DPR never uses skill or win rate.

## Review Focus

1. Fusing the last copy of an equipped card: the deck stays valid and the slot moves up. Test in Task 5.
2. A fusion that would use a variant copy: refused until confirmed, and nothing is spent. Test in Task 5.
3. Enough copies but too few Credits: nothing changes, and neither copies nor a Catalyst are lost. Test in Task 5.
4. A hacked client sends NaN, negatives, tables or huge strings to a remote: rejected without an error. Test in Task 9.
5. A save written by a newer build, or with corrupt counts: a newer save is never overwritten; bad entries are dropped and the deck is repaired. Test in Task 8.
