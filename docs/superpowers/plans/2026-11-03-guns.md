# Guns Implementation Plan (Phase 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build all 4 classes and 9 guns in the test room: shooting, server hit checking, damage, health, ammo, reloading, recoil and a basic HUD.

**Architecture:** Gun data and every rule live as pure modules in `src/shared/Guns/` and run under Lune. The server owns health, ammo and hits, and rewinds targets using its own position history. The client sends only aim, firing time and the button pressed, then shows recoil, a blockout gun and the HUD.

**Tech Stack:** Luau, Rojo 7.7.1 with live sync, Lune 0.11.1.

**Spec:** `docs/superpowers/specs/2026-11-03-movement-combat-design.md` (Classes and guns, Hit checking, Cheat checks, Architecture)

## Global Constraints

- Health is 100 and does not regenerate.
- Headshots: M4 2x, AK-47 instant kill, SMG 2x, Sniper instant kill, Shotgun 2x per pellet, every sidearm 2x.
- The server keeps 1 second of position history and rewinds at most 200ms.
- The client never reports damage or health. Remote payloads go through a parser, as in `Requests.luau`.
- Guns add 0 to Deck Power Rating.
- Input is read only through `src/client/Input.luau`.
- Sprinting and jumping carry a small accuracy penalty. Players can shoot during every move except a climb.
- Save version 2 adds class and Assault rifle. Version 1 saves migrate to Assault with the M4.

## Plan decisions (the spec leaves these open)

| Decision | Value | Why |
| --- | --- | --- |
| Spare ammo | Unlimited; only the magazine runs out | Rounds are short, and the spec gives magazine sizes only. |
| Sidearm range | 100% to 40 studs, 70% by 90 | The spec gives no sidearm range. |
| Keys | Left click fire, right click aim, R reload, 1 primary, 2 sidearm | PC defaults. |
| Class change | Number row is taken, so B cycles class and N swaps the Assault rifle, in the test room only | Phase 4 replaces this with the between-round screen. |
| Spread | Rolled by the server | A client cannot remove spread by cheating. |
| Recoil | Moves the camera on the client | Aim is sent after recoil, so recoil affects real shots. A no-recoil cheat stays possible; Risks covers this. |
| Hitboxes | A sphere for the head and a vertical cylinder for the body | Rewinding is pure maths and testable under Lune. Slide and crouch poses lower them. |
| Damage over range | Straight line between the two distances, then flat | Simple to read and tune. |
| Death in the test room | Respawn after 3s with a full magazine | Phase 4 replaces this with spectating. |
| Test target | One dummy in the test room, using real health | River can test damage alone. |
| View model | Grey block held in view, no animations | Art comes later. |

**Starting values to tune by feel:**

| Gun | Hip spread | Aimed spread | Recoil per shot |
| --- | --- | --- | --- |
| M4 | 1.5° | 0.2° | 0.1° |
| AK-47 | 2° | 0.4° | 1.1° |
| SMG | 2° | 0.8° | 0.35° |
| Sniper | 7° | 0° | 5° |
| Shotgun | 5° | 4° | 4° |
| Pistol | 1.5° | 0.4° | 0.6° |
| Machine pistol | 2.5° | 1° | 0.4° |
| Revolver | 2° | 0.3° | 2.5° |
| Auto-pistol | 1.8° | 0.6° | 0.5° |

Sprinting multiplies spread by 1.4, and being in the air by 1.7. Aimed field of view is 60, and 30 for the Sniper.

**Out of scope:** ability cards, rounds, teams, spectating, kill feed, gun art and sound, gun upgrades, friendly fire rules.

## Review Focus

1. A shot with a future, old, NaN or huge firing time: clamped to the rewind limit or rejected, never a crash. Test in Task 3.
2. Firing during a reload, or with an empty magazine: no shot and no ammo change. Test in Task 2.
3. Swapping guns during a reload: the reload cancels and each gun keeps its own ammo. Test in Task 2.
4. A target or shooter who died or left between firing and arrival: no damage and no error. Test in Task 4.
5. A shot with an origin far from the shooter's rewound position: rejected. Test in Task 3.

## Risks

| Risk | Mitigation |
| --- | --- |
| A no-recoil cheat works, because recoil lives on the client | A recoil check can follow if it matters |
| A cheat can claim to be aiming all the time for tighter spread, because aiming is client input | Stays within the gun's aimed accuracy; the server can later track how long a player has aimed |
| The body hitbox does not match what players see | Sizes are single values, tuned in River's test |
| The chain-jump speed makes fast targets too hard to hit | Tune movement or hitboxes once guns are in, starting with the Sniper |
