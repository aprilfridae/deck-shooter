# Movement Implementation Plan (Phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build first-person walk, sprint, slide, slide-cancel and jump in a test room, with server speed checks.

**Architecture:** Pure movement rules live in `src/shared/Movement/` and run under Lune. The client drives a Humanoid from those rules, and the server samples positions and enforces a speed limit.

**Tech Stack:** Luau, Rojo 7.7.1 with live sync, Lune 0.11.1, Studio MCP for playtests.

**Spec:** `docs/superpowers/specs/2026-11-03-movement-combat-design.md` (Movement, Cheat checks, Build phases)

## Plan decisions (the spec leaves these open)

| Decision | Value | Why |
| --- | --- | --- |
| Crouch speed | 8 studs/sec | The spec names crouch but gives no speed. |
| Speed at the end of a slide | 24 | Hands off into a sprint without a stutter. |
| Slide-cancel carry | Current speed fades to the normal speed over 0.25s after landing or cancelling | "Keeps current speed" needs an end point. |
| Air speed | Holds takeoff speed until landing | Makes slide-jumps reward timing. |
| Keys | Left Shift sprint, C or Left Ctrl crouch and slide, Space jump | PC defaults. |
| Field of view | 80 | Wider view for fast movement. |
| Speed limit | 39 studs/sec over a 0.5s window, plus 4 studs of lag allowance | Slide (34) with 15% margin. See below. |
| Rising limit | 60 studs/sec | Above Roblox's default jump. |
| Strikes | 5 strikes removes the player and logs it | Phase 4 changes the removal from a kick to removal from the match. |

**Change from the spec's wording:** the spec says "fastest legal speed for their current state". Slide-jumping can legally hold about 33 studs/sec for long stretches, and a state reported by the client can be faked. The limit is therefore one speed for all states. A cheater can move at up to about 39 instead of 24 without being caught, and larger cheats are caught. Phase 3 adds Phase Dash to this limit.

**Out of scope:** guns, abilities, matches, viewmodels, final animations, touch and controller input, hover cheats.

## Global Constraints

- Walk 16; sprint 24, any direction, no stamina; slide starts at 34 and slows over 0.7s, starts from a sprint, any direction, 1s cooldown; jump or crouch ends a slide early and keeps current speed; default jump height.
- The camera is first-person. Players can look in any direction during every move.
- Other players see the full character sliding and turning.
- A failed check moves the player back to the last valid position and adds a strike. There are no automatic bans.
- Input is read through one module, so touch and controller can be added later.
- Modules in `src/shared/` use no Roblox APIs, sit in flat folders with no `init.luau`, and require siblings with `require("./Name")`.
- Client values never decide outcomes.

## Review Focus

1. A server move such as a respawn or pull-back: adds no strike. Test in Task 2.
2. A lag spike where the position jumps after a long silence: legal travel adds no strike. Test in Task 2.
3. A long fall, or falling off the map: never a strike. Test in Task 2.
4. Sliding off a ledge: the slide ends cleanly and the player isn't stuck low or fast. Test in Task 1.
5. Crouch held before sprinting, or pressed during cooldown: no slide starts. Test in Task 1.

### Task 4: Server speed enforcement

**Files:**
- Create: `src/server/MovementGuard.server.luau`

**Interfaces:**
- Consumes: `SpeedLimit`, `MoveConfig`
- Produces: logs `[MovementGuard] strike N/5 for <userId>`; the character attribute `MoveStrikes`
