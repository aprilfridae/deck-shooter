# HUD Typography Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder HUD with layout A, set in KH Interference and PP Fraktion, drawn from image sheets because Roblox can't import fonts.

**Architecture:** A Python tool turns fonts into sheets plus generated glyph data. Pure Luau modules lay out text and format HUD values, tested in Lune. A client `TypeLabel` draws laid-out text from pooled `ImageLabel`s, and `Hud.client.luau` uses it.

**Tech Stack:** Luau, Rojo, Lune tests, Python with Pillow.

**Spec:** `docs/superpowers/specs/2026-11-05-hud-typography-design.md`

## Global Constraints

- Sizes are at 720 tall. Scale is screen height / 720, held between 0.75 and 2.
- Green is (57, 255, 90). Empty cooldown segments are (40, 40, 46).
- The dark copy behind each character is offset by (1, 2).
- The crosshair and hit marker keep their current code, parent and pixel size.
- Font files never go in the repo. Sheets are no bigger than 1024 by 1024.
- No commits unless River asks. Scripts are never edited through Studio. Rojo syncs them.
- Test command: `export PATH="$HOME/.rokit/bin:$PATH"; lune run tests/run.luau`. A new spec needs a `listed` entry and a `require` in `tests/run.luau`.
- River does all Play testing.

## Review Focus

1. Slot whose cooldown is 0: no division by zero, and the bar reads full. Test in Task 3.
2. Ammo attribute missing just after spawn: label shows nothing instead of erroring. Tests in Tasks 2 and 3.
3. Text getting shorter, like `RELOADING` to `M57 / 30` or 100 to 99: no leftover letters. `TypeLabel` hides unused pieces; not reachable from Lune, so reviewer reads it and it's on River's checklist.
4. Window resized in play: the HUD rescales and stays in its corners. `HudText.scale` is tested in Task 3; the viewport hookup is on River's checklist.
5. Thin glyph edges bleeding from neighbours on the sheet. Task 1's test pins that sheet rectangles don't touch.

### Task 1: Font export tool

**Files:**
- Create: `tools/export_font_atlas.py`, `assets/hud/*.png` (generated), `src/shared/Guns/Hud/GlyphData.luau` (generated)
- Test: `tests/glyphdata_spec.luau`

**Interfaces:**
- Produces: `GlyphData[style] = { sheet: string, source: number, space: number, glyphs: { [string]: { x, y, w, h, ox, oy, advance } } }`, in source pixels. `style` is `"Number" | "NumberThin" | "Label" | "LabelBold"`. `ox, oy` are from the pen on the baseline, with `oy` negative upward. `sheet` is the PNG's base name.

- [ ] **Step 1: Write the failing test** in `tests/glyphdata_spec.luau`:
  - `"has every character a style promises"`: `Number` has `0123456789/+`; `NumberThin` has `0123456789+`; `Label` and `LabelBold` have `A-Z`, `0-9` and `/:.-+`.
  - `"has a space width for every style"`: `space > 0`, including `Number`.
  - `"stays on a 1024 sheet"`: every glyph has `x >= 0`, `y >= 0`, `x + w <= 1024`, `y + h <= 1024`.
  - `"keeps glyphs apart"`: no two glyphs' rectangles in a style come within 2 pixels of each other.
- [ ] **Step 2: Run the tests.** Expected: FAIL requiring the missing module.
- [ ] **Step 3: Implement `tools/export_font_atlas.py <font folder>`.** Style table from the spec's Export section, with sources 138 and 36. Find each font by filename under the folder, so trial names and full names are both listed as a filename pattern (`KHInterference*-Bold.otf`, and so on). Measure with `font.getbbox(c, anchor="ls")` and `font.getlength(c)`. Pack in rows with 4 pixels of padding. Draw white on transparent. Write the sheets, then `GlyphData.luau` with sorted keys and a `-- Generated by tools/export_font_atlas.py` header. `space` is `font.getlength(" ")`.
- [ ] **Step 5: Run the tool on River's unpacked fonts, then the tests.** Expected: 0 failed. Look at one sheet with the Read tool to confirm clean letters.

### Task 2: Text layout

**Files:**
- Create: `src/shared/Guns/Hud/TypeLayout.luau`
- Test: `tests/typelayout_spec.luau`

**Interfaces:**
- Consumes: `GlyphData`.
- Produces: `TypeLayout.lay(text: string, style: string, size: number, tracking: number): (number, { Placed })`. Returns width and placed glyphs. `Placed = { x, y, w, h, rectX, rectY, rectW, rectH }`. `x, y, w, h` are at display size, relative to the start of the baseline. `rect*` are sheet pixels. Tracking goes between characters, not after the last.

- [ ] **Step 1: Write the failing test.** With `adv = GlyphData.Number.glyphs["8"].advance * 46 / 138`:
  - `"measures by advance"`: width of `lay("88", "Number", 46, 0)` is close to `2 * adv`.
  - `"adds tracking between characters only"`: width of `lay("88", "Number", 46, 3)` is close to `2 * adv + 3`.
  - `"uppercases"`: `lay("m57", "Label", 12, 0)` width equals `lay("M57", "Label", 12, 0)` width.
  - `"gives an unknown character a space's width and draws nothing"`: `lay("A", "Number", 46, 0)` returns width close to `GlyphData.Number.space * 46 / 138` and zero placed glyphs.
  - `"draws nothing for a space"`: `lay("A B", "Label", 12, 0)` places 2 glyphs.
  - `"handles empty text"`: width 0, zero placed.
- [ ] **Step 2: Run the tests.** Expected: FAIL requiring the missing module.
- [ ] **Step 3: Implement `lay`.** Walk the uppercased text with a pen. Advance by each glyph's `advance * size / source`.
- [ ] **Step 4: Run the tests.** Expected: 0 failed.

### Task 4: Upload sheets and draw text

**Files:**
- Create: `src/shared/Guns/Hud/FontImages.luau`, `src/client/TypeLabel.luau`

**Interfaces:**
- Consumes: `TypeLayout.lay`, `GlyphData`.
- Produces: `FontImages[style]: string` (an `rbxassetid://` id). `TypeLabel.new(parent: GuiObject, options: { style, size, tracking, color, right: boolean?, position: UDim2 })`, with `:set(text: string)`, `:width(): number`, `:setColor(color: Color3)`, `:setPosition(position: UDim2)`, `:setVisible(visible: boolean)`.

- [ ] **Step 1: Upload the four sheets.** Try the Studio upload tool. If it fails, ask River to use Asset Manager and send the ids. Put the ids in `FontImages.luau`.
- [ ] **Step 2: Implement `TypeLabel`.** A zero-size `Frame` at `position`, its origin on the baseline, with its own `UIScale` of `size / source`. Inside, glyph pieces use whole source-pixel offsets (`round(x * source / size)`), so small text doesn't drift from rounding. Nested `UIScale`s multiply, so this works inside the HUD's scale. Right-aligned text starts at `-width`. Each character is a shadow `ImageLabel` (black, `ZIndex` 1, offset by (1, 2) display units) and a glyph `ImageLabel` (`ZIndex` 2). `:set` returns at once if the text is unchanged, reuses pieces and hides the spare ones.
- [ ] **Step 3: Compile check.** Run the session's `compile_all.luau`. Expected: all compiled.
